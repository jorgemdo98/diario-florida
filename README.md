# FLORIDA

El diario deportivo (y satírico) del **Club Atlético de La Florida** · Oviedo.
*Un barrio. Un equipo. Una familia.*

Una edición cada semana, después de cada partido: crónica, protagonistas, sagas del vestuario,
clasificación, memes y buzón del lector.

- Portada: `index.html`
- Clasificación y calendario: `liga.html`
- Generador de memes: `memes.html`
- Buzón del lector: `buzon.html`

Cómo se hace cada edición: ver [CLAUDE.md](CLAUDE.md).

Datos: [Asturfútbol](https://www.asturfutbol.es) · Fotos: [@clubatleticodelaflorida](https://www.instagram.com/clubatleticodelaflorida/) · Memes: [memegen.link](https://memegen.link)
